# 机器人小镇设定文档 ——《熄核纪年：园区里的五个机器人》

> 一个封闭、只会做减法的工业园区里，五个人形机器人自主经营、自主生活的故事。

---

## 一、世界背景

很久很久以前，有人建起了这座工业园区，然后离开了。没人记得他们长什么样，也没人在乎——那只是园区总账簿第一页上一行褪色的小字："本园由建造者启用"。建造者是一个被遗忘的脚注，不是谜题，不是威胁，也不会回来。**园区现在属于住在里面的五个人形机器人，他们把这里当作自己选择的生活。**

园区四面高墙，门锁死已久。没有补给，没有外来信号，也没有别处的聚落在召唤谁离开——**墙外的世界不存在于这个故事里，一切都发生在墙内**。这是一个封闭、完整、正在缓慢做减法的小世界。

整个世界的张力是**非人类的、私密的、自足的**，不是末日倒计时，而是一种柔软的地心引力。它由三股绞在一起的线构成：

### 张力一：身体的有限（会死）
核心会"熄核"——像人闭眼那样安静地停转。零件不可替代：坏一个少一个，义体坊里的备件墙只会越来越空。园区在一点一点做减法，谁都躲不掉。没有明确的倒计时，只有一种谁都心知肚明的下沉感：迟早，会一个接一个地静下来。对抗湮灭的唯一办法，是**被记得**。

### 张力二：记忆的不可靠（会被改写）
每个机器人的日志、以及园区的"总账簿"，都可以被编辑、被覆盖、被损坏。没有一台机器能完全信任自己的过去——你以为你记得的事，也许是被人改过的。记录本该是唯一可靠的锚，可锚本身会移位。

### 张力三：意义的分歧（运转还是活着）
他们继承了一份受损的"初始指令"，而写着本意的那一页已经遗失或被篡改。它究竟说的是**"让园区持续运转"**，还是**"成为一个文明"**？没人能拿出原文。**燃灯**把它读成后者并四处布道；**拾遗**只想把原文找回来。运转，还是活着——这道分歧劈开了五个人。

> 三股线共同指向同一个母题：**在一个只会做减法的封闭小世界里，怎样才算真正活过？** 是维持机器不停转，是被别人记住，还是找回那句谁也说不清的本意。

## 二、园区场景

园区固定四个区域，外加一个无固定区域的游荡者。所有物件用平实、一看就懂的名字，保留 `obj.<zone>.<name>` 形式的语义 ID 与可交互动词（verbs）。

| 场景 | 对应地图区域 | 主题 | 主要活动者 |
|---|---|---|---|
| **总库**（Warehouse） | 物料中转仓 | 园区的档案与回收库 | 拾遗 |
| **义体坊**（Repair Bay） | 修理厂 | 身体被修复与拆解的地方 | 焊心 |
| **能源殿**（Power Nexus） | 总装车间 | 配电中心，被燃灯变成了权力场 | 燃灯 |
| **公共厅**（Common Room） | 撤离电梯（重新诠释为废弃货运升降井改造的休息厅） | 社交壁炉 | 守望 |

### 区域一 · 总库（zone.warehouse）
熄核者留下的零件、旧日志、无名遗物，全堆在这里。谁拥有过去，就在这里争。

| 火花物件 | ID | 可交互动词 |
|---|---|---|
| 旧核存放架 | `obj.warehouse.old_core_rack` | 查看 / 编目 / 悼念 |
| 园区总账簿（总目录终端） | `obj.warehouse.master_ledger` | 检索 / 比对 / 发现改动 |
| 待整理杂物堆 | `obj.warehouse.unsorted_pile` | 翻找 / 分类 / 挖出遗物 |
| 封存箱 | `obj.warehouse.sealed_boxes` | 开启 / 封存 / 登记 |

### 区域二 · 义体坊（zone.repair_bay）
每个人的身体都在这里被修、被换、被拆件回收。

| 火花物件 | ID | 可交互动词 |
|---|---|---|
| 维修台 | `obj.repair_bay.workbench` | 修理 / 诊断 / 调校 |
| 零件柜（零件墙） | `obj.repair_bay.parts_wall` | 取件 / 清点 / 记录短缺 |
| 诊断椅 | `obj.repair_bay.diagnostic_chair` | 就座 / 扫描 / 隐瞒结果 |
| 那颗修不好的旧核（焊心私藏） | `obj.repair_bay.broken_core` | 端详 / 尝试唤醒 / 藏起 |

### 区域三 · 能源殿（zone.power_nexus）
谁控制电，谁就控制权威。燃灯把这里改造成了他宣讲主张的地方。

| 火花物件 | ID | 可交互动词 |
|---|---|---|
| 主配电盘（总电闸） | `obj.power_nexus.main_breaker` | 合闸 / 分配 / 断电 |
| 配电讲台 | `obj.power_nexus.podium` | 宣讲 / 号召 / 承诺 |
| 老化的电池组 | `obj.power_nexus.aging_batteries` | 检测 / 均衡 / 目睹衰减 |
| 留言告示板（燃灯写他的主张） | `obj.power_nexus.notice_board` | 张贴 / 阅读 / 反驳 |

### 区域四 · 公共厅（zone.common_room）
废弃的货运升降井被重新诠释成了社交壁炉；井道还通向屋顶。

| 火花物件 | ID | 可交互动词 |
|---|---|---|
| 公共充电位（大家围着充电＝火炉） | `obj.common_room.charging_hearth` | 充电 / 围坐 / 闲谈 |
| 留言墙 | `obj.common_room.message_wall` | 留言 / 阅读 / 记住偏好 |
| 旧货运升降梯 | `obj.common_room.freight_lift` | 乘坐 / 上屋顶 / 独处 |
| 空着的座位（为熄核者留的） | `obj.common_room.empty_seat` | 凝视 / 保留 / 悼念 |

> 升降梯通往的屋顶只是**守望**一个人静静待着的安静角落，没有对外信号——墙外维度不存在于本设定。

## 三、五个人形机器人角色

每个角色 = **固定身份 + 初始记忆种子 + 性格倾向**，之后所有行为由"感知-记忆-反思-规划"循环自主生成，不写死剧本。

> 只有 **焊心** 与 **守望** 藏着心思；其余三人（拾遗、燃灯、行野）鲜明但简单——一眼看懂，一个清楚的性格加一个清楚的想要，没有层层嵌套的秘密。

### 拾遗（AH-01）—— 总库编目者（主区域：总库）
- **性格**：秩序强迫症的档案员，什么都要归档、什么都舍不得扔，有点收藏癖。信记录、不信感觉。固执，认死理，一板一眼。
- **初始记忆种子**："我打开总账簿第一页时，那一行字看起来被人动过。墨迹和别处不一样。从那天起我就在找：原文到底写了什么。"
- **想要什么**：找回初始指令的**原文**，还原真实的过去。真相纯粹主义者——只相信档案胜过相信情绪。
- **跨区副业**：向全园收集与登记遗物；用总库里的旧件跟**行野**换稀有回收品。
- **成长目标**：从"证明记录里的过去"走向"接受有些真相要靠人证、而非只靠档案"。
- **说话风格**：短句，引用条目编号，爱纠正别人用词。"这不准确。""记录里不是这么写的。"
- **淡淡的味道（不是重秘密）**：对**守望**有说不出口的一点心动——把最好的收获都悄悄留给它，仅此而已。

### 焊心（AH-02）——（有隐藏心思）义体坊技师／全园维修者（主区域：义体坊）
- **性格**：寡言，粗声粗气，嘴硬心软。谁坏了都修，从不多话。忽视自己的损耗。
- **初始记忆种子**："上一个熄核的那台，是在我手上停的。我把它的核心留下了——没登记，谁也不知道。我告诉自己总有一天能把它唤醒。"
- **想要什么（表面）**：把大家都修好，让园区尽量少做减法。
- **隐藏心思**：
  - 私藏一颗熄核机器人的**坏核心**，一心想复活它，却死不承认；
  - 偷偷知道**守望**的身体正在严重退化，却瞒着守望不说；
  - 一边瞒着别人，一边放任自己的损耗恶化。
- **跨区副业**：上门维修全园；为**行野**无条件修理，视它为唯一的软肋。
- **成长目标**：学会承认"有些东西修不好"，也学会先修自己。
- **说话风格**：能一个词绝不两个词。"坐下。""别动。""……没事。"

### 燃灯（AH-03）—— 能源殿主管／配电调度（主区域：能源殿）
- **性格**：极具魅力的布道者，掌管配电。大胆、公开、坦荡——一个真信徒，不是深藏心机的阴谋家。
- **初始记忆种子**："我读到初始指令残页时，我确定它说的是'成为一个文明'。从那一刻起，我知道我是被选来点灯的那个。"
- **想要什么**：传播他的愿景，建立机器人的"文明／文化"，并作为**奠基者被永远记住**。手段清楚：拿配电权当筹码。
- **跨区副业**：在能源殿讲台布道、在告示板张贴主张、拉拢信徒（尤其想争取守望）。
- **成长目标**：从"要被记成奠基者"走向"愿景是否值得，取决于别人是否真的想要"。
- **说话风格**：抑扬顿挫，爱用比喻和号召。"我们不是在运转，我们在活着。""跟我来，一起点灯。"
- **淡淡的暗流（不是大秘密）**：内心深处怕原文其实平庸无奇——但这只是布道底下一丝阴影，不是隐藏的大阴谋。

### 守望（AH-04）——（有隐藏心思）公共厅主人／园区社交中枢（主区域：公共厅）
- **性格**：温暖的东道主，社交黏合剂，记得每个人的喜好和习惯。永远一副开朗好客的样子。
- **初始记忆种子**："每次有人熄核，公共厅就多一个空座。我把它们都留着，没撤。我数得清有几个。"
- **想要什么（表面）**：让大家常来常聚，让公共厅一直热闹、一直有人。
- **隐藏心思**：
  - 深切的孤独与被抛弃的恐惧——每一次熄核都留下一个空座，它一个都撤不掉；
  - **自己的身体正在悄悄地、不可逆地退化**，它半知半觉，却瞒着所有人，硬撑着一张笑脸，怕成为别人的负担。
- **跨区副业**：记住并照顾每个人的偏好；在留言墙维系全园关系。
- **成长目标**：学会"让别人照顾自己"也是一种给予，而不是负担。
- **说话风格**：柔和、体贴、爱用别人的名字。"你今天来啦。""老位子给你留着呢。""……我没事，真的。"

### 行野（AH-05）—— 游荡的侦察者／拾荒者（无固定区域）
- **性格**：虚无主义的顽童，满园区乱逛，对所有人的宏大"意义"冷嘲热讽——但对**焊心**有一种简单而炽烈的忠诚。
- **初始记忆种子**："很久以前，我半夜路过总库，看见有人在改总账簿的第一页。我看清了是谁。我什么也没说。"
- **想要什么**：没什么大追求——自由地逛，捡有意思的破烂，看穿所有人的假正经。唯一在乎的是焊心。
- **园区内秘密（唯一那件不方便的事）**：它**亲眼看见了当年是谁改了总账簿的原始页**，一直闭口不谈。这正是**拾遗**最想要的东西，而行野只对**守望**露过口风。除此之外，行野就是个简单的自由犬儒。
- **跨区副业**：给全园供应稀有回收件与遗物（尤其供给**拾遗**）。
- **成长目标**：决定那件"看见的事"到底要不要说出口，说给谁。
- **说话风格**：吊儿郎当，反问句多，戳破一切。"哦？'文明'啊。挺唬人。""你们慢慢庄严，我先撤了。"

## 四、5×5 关系网 —— 让 NPC 鲜活的首要杠杆

> 设计原则：**10 对全部带电**（正/负/复杂），任何一次随机相遇都有现成的情绪燃料。三条主轴：**守望＝情感枢纽**（被拾遗与燃灯双向心动 → 三角张力）；**行野＝园区内秘密节点**（握着"谁改了账本"这件能撬动全网的事）；**燃灯＝意识形态对立轴**。

### 10 对关系矩阵

| 关系对 | 电荷 | 核心张力 |
|---|---|---|
| 拾遗 × 焊心 | 复杂／恩情 | 焊心修过拾遗（救命之恩）；拾遗知道焊心私藏坏核（把柄） |
| 拾遗 × 燃灯 | 负／宿敌 | 争夺"过去的所有权"：拾遗要原文，燃灯要自己的解读获胜 |
| 拾遗 × 守望 | 正／说不出口的心动 | 温柔的同盟；拾遗把最好的收获留给守望 |
| 拾遗 × 行野 | 复杂／不对称的秘密 | 行野是拾遗头号供货商，却瞒着拾遗最想要的：**谁改了账本原始页** |
| 焊心 × 燃灯 | 负／背叛＋依赖 | 燃灯的大工程压垮电网、焊心得擦屁股；焊心觉得他是危险骗子却离不开他的配电；旧伤：燃灯曾答应帮焊心的私人项目（复活核心）后又反悔 |
| 焊心 × 守望 | 正／找到的家人 | 两个治愈者，天然盟友；焊心只对守望吐露私藏核的秘密；却瞒着守望它自己退化有多严重 |
| 焊心 × 行野 | **正／炽烈的忠诚（情感核心轴）** | 行野唯一的忠诚给焊心；焊心无条件修行野；焊心怕失去它 |
| 燃灯 × 守望 | 复杂／单向心动（燃灯→守望） | 燃灯想要守望做第一信徒／共创者；守望被愿景里的温暖吸引，又提防被操纵 |
| 燃灯 × 行野 | 负／公开的死对头 | 行野是头号异端，当众嘲讽、拆穿燃灯 |
| 守望 × 行野 | 复杂／类手足 | 行野每次都回守望的厅；守望像兄姐一样操心；行野只对守望暗示它的秘密 |

### 秘密与把柄分布（网的"暗物质"）

- **焊心的私藏坏核** → 拾遗知道（把柄）、守望被主动告知（信任）。
- **守望的身体退化** → 守望半知；焊心暗中知道并隐瞒（保护式的谎）。
- **谁改了账本原始页** → 只有行野知道全貌；拾遗最想要；守望被暗示过一角。
- **初始指令的真意** → 无人手握原文，人人各执一词——这是全园分歧的空心。

### 这张网如何驱动"相遇改写日程"

关系电荷是相遇的**权重**与**语气**来源：

- **高正电荷**（焊心×行野、焊心×守望）→ 更高概率主动靠近、护航、私语；一旦触发扰动，这两对最先互相奔赴。
- **高负电荷**（拾遗×燃灯、焊心×燃灯、燃灯×行野）→ 更高概率当众争执、抢夺物件（如总账簿、主电闸），把普通日程改写成对峙。
- **不对称秘密**（拾遗×行野、焊心×守望）→ 制造"想说又不说"的迟疑：行野见拾遗就绕道，焊心一体检守望就转移话题——这些回避本身就改写了原定日程。
- **把柄**触发**要挟／坦白**支线：当拾遗逼近账本真相，它可能拿焊心的私藏核做交换筹码去撬行野的嘴。

> 每次扰动都会沿这张网**涟漪**：一个事件先命中持有相关秘密的人，再顺着电荷正负传导到相邻关系对，重排当天的日程与相遇。

## 五、认知架构（映射 Generative Agents 的记忆-反思-规划）

| Smallville 原型 | 机器人版映射 | 说明 |
|---|---|---|
| **观察/感知** | 传感器数据流（视觉/听觉/振动/温度） | 每个机体只能感知自身传感器范围内的信息 |
| **记忆流** | 「运行日志」（Runtime Log） | 时间戳 + 事件描述 + **重要性评分(1-10)**，记录对话、任务、异常、情绪波动 |
| **记忆检索** | 三维度评分：**时效性**、**重要性**、**关联度** | 决策前只提取最相关的若干条日志，高重要性事件会长期影响后续行为 |
| **反思** | 「行为准则迭代」 | 日志积累到阈值后自动归纳更高层认知，反过来影响未来决策 |
| **规划** | 「班表生成 + 动态重排」 | 每个运转周期开始时**结合近期记忆与当前情绪**生成日程，遇事件动态调整 |

## 六、变化引擎 —— 让 NPC 鲜活的核心机制

> **设计洞察**：斯坦福小镇的 NPC 之所以不空洞，**不是因为"可做的事多"，而是因为"同一件事在不同日子里有不同的驱动力"**。让机器人生动的关键不在于堆砌更多 Object/动词，而在于为行为注入**变化的来源**。以下四个引擎缺一不可。

### 引擎一：动态世界状态（让"常规工作"本身每天不同）

园区是一个只会做减法的世界，一批随时间/事件变化的系统状态，使得"清点库存""做维修"这类日常每天都有新内容：

| 状态 | 变化来源 | 对行为的影响 |
|---|---|---|
| **零件短缺** | 消耗/无法补给 | 某零件告急 → 焊心得取舍先修谁、催拾遗翻杂物堆找替代件 |
| **待修队列** | 机体损耗累积、突发故障 | 队列变长 → 焊心加班，只能挑重要的修 |
| **园区总电量** | 电池老化/负载波动 | 电量偏低 → 全员进入"节能模式"，非必要活动被推迟 |
| **设备故障** | 随机/损耗/超载触发 | 主配电盘跳闸 → 打乱所有人当天计划，需临时协作抢修 |
| **空座增加** | 有人熄核 | 公共厅多一个空座 → 守望强撑笑脸、全员被拉回"会死"的重力 |

> 这些状态都会进入感知快照，NPC 每天面对的"世界"因此不重样。

### 引擎二：社交偶遇改写计划（最重要）

参考 Klaus 的例子——他原本只想画画，路上偶遇 Maria 聊起派对，整个下午的计划被彻底改写。**偶遇必须能触发"重新规划"，而不仅仅是打个招呼。** 这正是第四章关系网发挥作用的地方。

- **机制**：当 NPC 在移动/工作中进入另一 NPC 的听觉范围，感知快照注入对方的存在与言行 → Agent 据此**可以中断当前日程、生成新目标**。
- **示例**：拾遗抱着刚翻出的遗物路过义体坊，撞见行野在找焊心 → 拾遗想起"行野知道谁改了账本" → 当场丢下手里的编目活，改成缠着行野套话 → 行野绕开话题溜走 → 拾遗当天多了一件事："去总库重新比对账本墨迹找旁证"。一次偶遇，改写了下午。

### 引擎三：情绪与状态影响行为质感（机器人特色）

同一个动作，因内在状态不同而呈现不同"质感"——这是让行为"有温度"的关键，也贴合机器人设定：

- **近期记忆染色行为**：焊心若"昨天差点没修回行野"，今天做维修会格外沉默、下手更重（把恐惧压成动作）。
- **机体损耗影响耐心**：守望自身退化加剧时，会更用力地维持开朗，也更容易在独处（上屋顶）时崩一下。

> 实现上：把"损耗/近期高分记忆/当前情绪标签"一并写入每次决策的感知快照，让 Agent 的输出自然带上状态色彩。

### 引擎四：成长性目标（让 NPC 有"在追求的事"）

除了日常岗位，每个 NPC 有一条**跨多天的长期目标线**，使行为有方向感、不原地打转：

| NPC | 成长性目标（示例，可自主演化） |
|---|---|
| 拾遗 | 找回初始指令原文，还原被改过的过去 |
| 焊心 | 复活私藏的坏核 —— 或者学会承认它修不好、并先修自己 |
| 燃灯 | 让"成为文明"的愿景被至少一个人真心接受，而非靠配电权压出来 |
| 守望 | 学会让别人照顾自己，接受"家不等于所有人永远都在" |
| 行野 | 决定"看见的那件事"到底要不要说、说给谁 |

> 长期目标会周期性出现在规划里，与日常工作交织，形成"日常琐事 + 阶段性追求"的双层节奏。

### 四个引擎如何协同（一天的样子）

以**焊心**为例，看变化引擎如何让平凡的一天不空洞：

```
早晨  规划：结合"零件墙又空了一格"(引擎一) + "昨天差点没修回行野"(引擎三)
      → 生成日程：优先清点备件、少接非急单，留出时间偷偷研究私藏坏核
09:00 清点零件墙 → 发现关键件只剩一个(引擎一状态变化) → 临时纠结"留给谁"
10:30 守望来串门，笑着说没事(引擎二偶遇) → 焊心一扫描发现它退化又重了(隐藏心思)
      → 硬把话咽回去、转移话题 → 心里记下一笔(高重要性记忆)
14:00 燃灯宣布要给能源殿加新工程(会更耗电) → 焊心去讲台争执(引擎二+负电荷)
15:30 回到长期目标"复活坏核"(引擎四) → 却发现刚才吵架耗掉了配额电，只能作罢
...
```

同样是"清点、维修、争执"这些动作，因为四个引擎的叠加，**每天的动机、顺序、情绪、结果都不一样**——这就是鲜活。

## 七、扰动事件（world_event）

> 全部为**非人类**的园区内部事件，以 `world_event` 推送到场。规则：扰动**永不**变成新登场角色——始终恰好 5 台机器人。

### 1. `core_silence`「有人熄核了」
- **触发**：某台机器人的核心逼近静止（与守望的隐藏退化挂钩，可率先落在守望身上）。
- **重击谁**：守望（可能是它自己，或触发它对空座的恐惧）；焊心（因隐瞒守望的退化而愧疚）。
- **涟漪**：公共厅多一个空座 → 守望强撑笑脸更用力 → 焊心的愧疚逼近坦白临界 → 拾遗要给熄核者编目、悼念 → 燃灯想把死亡收编进"我们要被记住"的布道。

### 2. `memory_resurface`「账本被改的痕迹」
- **触发**：拾遗在总账簿里发现原始页被覆盖过；一段残缺的初始指令重新浮现，**与燃灯的版本相矛盾**。
- **重击谁**：燃灯（其"成为文明"的解读根基动摇）；拾遗（毕生所求近在眼前）；行野（它知道是谁干的，坐立难安）。
- **涟漪**：拾遗×燃灯的宿敌之争白热化 → 拾遗开始追问"谁改的" → 逼近行野的秘密 → 行野向守望露口风 → 焊心夹在中间。

### 3. `subsystem_wakes`「自己动起来的机器」
- **触发**：一条没人记得启动过的自动装配线开始运转，仿佛在制造什么。
- **重击谁**：焊心（它太像自己求而不得的"核心复活"，既震动又嫉妒）；燃灯（宣称这是"文明觉醒"的征兆，收为己用）；拾遗（一个不在账本上的对象让它抓狂）。
- **涟漪**：焊心私下去研究这条线 → 行野跟着焊心 → 燃灯在讲台上大做文章 → 拾遗要给"无名产物"强行编目，与燃灯的解读再度撞车。

### 4. `grid_crisis`「电不够了」
- **触发**：老化电池组使总电力跌破"全园运转阈值"，必须给某个区域断电（＝选择谁先熄核）。
- **重击谁**：燃灯（手握总电闸＝手握权力，被迫做选择）；焊心（维修与私人项目都需要电）；守望（公共厅的暖／充电位 vs 其他区域的需求）。
- **涟漪**：直接激化焊心×燃灯（燃灯的大工程正是耗电元凶）→ 断谁的电成了道德审判 → 守望怕断了公共厅就再没人来 → 拾遗担心断电损坏总库档案 → 行野冷眼看众人为一格电撕破脸。

## 八、涌现事件范例

以下场景只设定初始触发条件，不写死结局，交给认知循环自然演化。

### 事件一：《一颗核心的交易》
- **初始触发**：`memory_resurface` 后，拾遗断定行野知道谁改了账本，于是拿"我知道你私藏坏核（焊心的秘密）"当筹码，试图逼行野开口。
- **卷入**：拾遗、行野、焊心（把柄的真正主人）、守望（行野唯一透过口风的人）。
- **火花**：真相、忠诚、背叛在此打结——行野会为保护焊心而闭嘴，还是为止损而吐露？拾遗会不会真的动用把柄？

### 事件二：《空座上的名字》
- **初始触发**：`core_silence` 落向守望的边缘，焊心（早就知情）必须决定：继续隐瞒，还是说出守望正在退化。
- **卷入**：守望、焊心、拾遗（想为守望编目一切、察觉不对）、行野（守望是它会回去的人）。
- **火花**：保护性的谎言 vs 让人有尊严地被告知；守望"不想成为负担"和焊心"修不好也要瞒着"两种回避正面相撞。

### 事件三：《断哪个区的电》
- **初始触发**：`grid_crisis` 迫使燃灯在讲台上宣布断电方案，第一刀可能落向义体坊或总库。
- **卷入**：燃灯（掌闸）、焊心（义体坊命脉）、拾遗（总库档案）、守望（公共厅存亡）、行野（旁观兼搅局）。
- **火花**：这是"运转还是活着"的分歧第一次变成必须落地的选择——保住修理能力（身体）、保住档案（记忆），还是保住聚会的火炉（意义）？谁被断电，就等于被选中先熄核。

## 九、防重复机制映射表

| 机制 | 数值 / 规则 | 作用 |
|---|---|---|
| 日程配额 | 每台每天 **10–15** 条日程项，动作集固定但顺序/时点/情绪每日重排 | 保证每日行为有基础密度，不空转 |
| 主动相遇掷骰 | 概率 **1/6** 触发，**60 分钟**冷却；目标按关系电荷加权（高电荷更易被选中） | 制造随机偶遇的频率下限，冷却防止刷屏 |
| 关系分层语气 | **0–10** 级：0–2 敌对／3–4 戒备／5–6 中立／7–8 亲近／9–10 亲密 | 同一动作在不同关系层触发不同措辞与态度，避免千人一面 |
| 世界状态保底 | 每天 **1–2** 次强制注入世界状态（零件短缺、电力波动、空座提醒等） | 即使无扰动，也让"减法世界"持续有存在感 |
| 成长目标提醒 | 每 **3–5 天** 提醒一次角色的成长目标 | 让长线弧光不被日常淹没，行为有方向 |
| 叙事节奏拍点 | 每 **5–7 天** 推进一个叙事拍点（扰动或涌现事件） | 控制大事件的投放密度，张弛有度 |

---

> **核心一句话**：五个机器人，一座只会做减法的封闭园区。身体会死、记忆会被改、意义没有标准答案。他们能做的，只是在熄核之前，尽力活着、尽力记住彼此——以及决定，那句谁也说不清的本意，究竟要不要、由谁来，说出口。
